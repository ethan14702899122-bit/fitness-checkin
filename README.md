# 练有所获 · 个人健身打卡

适合手机使用的中文静态网页应用。支持每周计划编辑、逐组重量与次数记录、组间计时、恢复打卡、历史记录、JSON备份导入导出及30天日历提醒文件。

## 本地运行

需要 Python 3，在本目录执行：

```sh
python -m http.server 8080 --directory dist
```

然后打开 http://localhost:8080 。无需 npm 安装、API Key 或付费 AI 接口。

## 部署

将 `dist` 目录交给任意支持 HTTPS 的静态网站托管服务。已移除原 Sites 托管标识及认证依赖。项目未自动配置 GitHub Pages，也不会因上传仓库而自动公开网站。

## 数据与迁移

- 训练记录保存在当前设备、当前网站来源的浏览器 localStorage 中，不会随源码提交到 GitHub。
- 换手机、浏览器或网站地址前，进入“我的设置 → 导出备份”；在新地址选择“恢复备份”。恢复将替换新设备现有数据。
- 清除网站数据、隐私浏览或浏览器存储回收可能导致丢失；定期保存 JSON 备份。
- 不要将个人训练备份、化验结果或其他个人健康数据提交到仓库。

## 提醒与验证边界

- 组间计时以页面运行时的设备时间为基准。后台或锁屏时提示音可能延迟，不是系统级闹钟。
- 每日两次提醒通过下载并导入 `.ics` 文件实现；依赖日历通知权限。重复导入可能产生重复事件。
- 未连接小米手环，未自动读取步数、心率或其他健康数据；手环振动需要在实际设备上验证。
- 统计基于用户填写；保存一条力量训练计为一次，不表示完成全部计划。
- 默认训练安排是可编辑的起始模板，器械、伤痛和负重需自行确认，不用于诊断或治疗。

## 技术

原生 HTML / CSS / JavaScript；Web App Manifest；Service Worker 缓存。同源资源支持缓存，首次打开需联网。字体使用可选的 Google Fonts，加载失败时回退到系统字体。

此源码包不包含个人训练记录、密码、访问令牌或原平台 Git 历史。
